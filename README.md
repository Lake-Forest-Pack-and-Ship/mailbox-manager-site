# Mailbox Manager site

The public home page and privacy policy for Mailbox Manager, served by GitHub
Pages at https://lfpackandship.github.io/mailbox-manager-site/.
Google requires both pages for the app's Google Drive sign-in. The app itself
is in the private `mailbox-manager` repo.

Update the privacy policy, and its date, whenever the app starts handling
data or Google access differently.

`google0d080c2eb1a68929.html` proves to Google Search Console that this site
belongs to the Mailbox Manager Google Cloud project, which Google requires to
approve the app's sign-in page. Don't delete or rename it: Google checks it
again from time to time.
